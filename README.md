# SE1010 – Dimensionering av bakaxel

Projekt i **Hållfasthetslära gk med projekt (SE1010)** vid KTH, 2026.

Syftet är att dimensionera bakaxeln på ett eldrivet fyrhjuligt fordon. Programmet ska kunna beräkna belastningar och erforderlig axeldiameter för varierbara fordons-, geometri- och materialparametrar.

Tre lastfall undersöks: **acceleration**, **bromsning** och **kurvtagning**. Dimensioneringen ska ta hänsyn till både begynnande plastisk deformation och utmattning.

Projektet utvecklas i **Python**. Beräkningar utgår från SI-enheter. En teknisk rapport ingår också i kursuppgiften.
